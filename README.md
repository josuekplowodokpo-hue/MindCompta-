# 📊 MindCompta Finance
> **Transforming financial management for students and SMEs in West Africa.**

MindCompta is a high-performance, static web solution designed to provide expert accounting advice and financial education. Based in **Lomé, Togo**, it bridges the gap between complex academic concepts and practical business management.

---

## ✨ Key Features
* **Viral Content Engine**: Mobile-first article pages designed for high engagement and social sharing.
* **Member-Only Access**: Secure reading environment requiring user authentication to access premium insights.
* **High Performance**: Built for the West African mobile market—fast loading speeds using parallel data fetching.
* **PWA Ready**: Can be installed on mobile devices for an app-like experience.
* **Video Integration**: Dedicated section for concrete, real-world financial tutorials.

---

## 🛠️ Tech Stack
* **Frontend**: HTML5, CSS3 (Tailwind CSS 3.x), JavaScript (ES6+).
* **Backend as a Service**: [Firebase](https://firebase.google.com/) (Firestore, Authentication, Hosting).
* **Design Philosophy**: "Zen" Minimalism—Focusing on typography and readability.

---

## 🚀 Speed & Optimization
MindCompta uses advanced frontend techniques to ensure a smooth experience even on 3G/4G connections:
* **Skeleton Screens**: Instant UI feedback during data fetching.
* **Parallel Fetching**: Using `Promise.all` to load articles and suggestions simultaneously.
* **Local Persistence**: Firebase Auth persistence to minimize redundant login checks.

---

## 🌍 Social Impact
MindCompta specifically targets the **Faculty of Economics and Management** students in Togo, providing them with clear explanations of lecture hall concepts and concrete examples to help them validate their teaching units.

---

## 👨‍💻 Development
This is a static site architecture. To run locally:
1. Clone the repository.
2. Open `index.html` via a local server (like Live Server in VS Code).
3. Firebase configuration is embedded in the scripts (API Key restricted).
